# 评测第十八阶段决策记录：受控模型对比

状态：已决策，2026-10-30。承接[路线图](evaluation-roadmap.md)的 P3 阶段及[第十七阶段决策](evaluation-v17-decisions.md)。

## 目标与范围

让管理员在现有评测台选择已登记的远程 Chat 模型，沿用相同任务、fixture、试验次数和请求预算运行，再用现有回归对比查看逐题变化。无需下载本地模型，也不在页面接收密钥或 URL。

## 决策

1. 新增服务端 `EVAL_LLM_MODELS` 环境变量，逗号分隔允许评测的 Chat 模型名；当前 `LLM_MODEL` 始终在列表中。首版只切换 Chat 模型，Embedding、Rerank、URL、密钥、温度和其余设置沿用当前服务配置。列表去重、限制长度和名称字符，拒绝客户端自行提交未登记模型。
2. 管理员目录接口只返回模型名、当前默认项及是否已配置远程密钥。离线模式不接受模型选择。实时模式省略模型时使用当前 `LLM_MODEL`，兼容旧调用。
3. 创建后台运行时解析并冻结所选模型和安全配置快照；实际执行使用该快照，不依赖随后环境变量变化。普通问数服务不受影响。运行记录和导出继续保存非敏感配置，历史运行缺少选择信息时维持“未知”解释。
4. 页面展示模型选择及确认信息。现有回归对比继续要求相同任务版本、fixture、模式和试验次数；模型差异由来源快照明确展示。界面提示任务选择和请求上限应一致，若预算不同则沿用现有警示。
5. 不自动发起两组远程运行，不做费用估计；管理员仍需逐次确认并受到每次运行的请求上限约束。模型比较是实验能力，当前任务集未全部人工核验，分数不代表已验证的真实能力。

## 验收

- 白名单外、非法名称和离线模式带模型选择均被拒绝。
- 后台排队到执行期间模型选择保持不变；运行记录写入实际模型。
- 前端可选择模型并用现有对比查看差异；普通问数配置不改变。
- 不需要真实 API 或本地模型即可完成单元测试、前端构建与离线 CI。
