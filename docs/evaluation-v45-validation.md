## 离线输入大小核对

使用旧运行 `f60a2e161439` 保存的三个 `standalone_query`、Schema 图和检索结果，重建单库 Agent 的模型输入；MCP 工具定义在两版中保持同一测试值。这是**JSON 字符数**，不是供应商 Token 数，也不是新模型成绩。

| 题目 | 默认版输入字符 | 紧凑版输入字符 | 减少 |
| --- | ---: | ---: | ---: |
| `mock.target_comparison` | 36,504 | 11,368 | 68.9% |
| `grain.unique_customers` | 34,487 | 10,520 | 69.5% |
| `time.july_august` | 37,549 | 12,191 | 67.5% |

紧凑版仅将完整 `retrieval.selected_fields` 命中对象换成有序 `selected_field_ids`；Schema 图、文本、低置信度候选、工具定义和确认参数仍在。真实模型调用可能受消息结构、服务端计数和输出长度影响，不能把以上比例当作 Token 节省比例。

旧作业 `stable000001` 的工作流指纹与新候选相同，Prompt 指纹不同；旧基线仍未自动批准。新版本尚未发起付费真实评测，正确率与真实 Token 变化待人工批准基线后运行受控候选确认。
