# 评测第五阶段决策记录

状态：已决策，2026-10-30。承接 [第四阶段决策](evaluation-v4-decisions.md)。

## 目标与范围

当前评测可比较正确性，缺少远程模型调用的耗时与用量证据。本阶段在评测运行中开启轻量遥测，记录每次 Chat、Embedding、Rerank HTTP 调用的类型、模型、耗时、请求尝试次数、成功状态及供应商返回的 token 用量。记录落在每个 trial 中，并汇总到运行和两次运行对比。

## 取舍

1. 默认业务请求不启用调用遥测，避免全局服务长期积累记录；评测专用 `ModelClient` 启用后按试验切片。
2. 保存摘要元数据，不保存 API Key、请求 URL、Prompt、Embedding 输入、响应正文或错误正文。
3. HTTP 请求的耗时包含重试与退避；试验总耗时另外按墙钟记录，包含检索、工具与本地执行。两者不能相加当作总耗时。
4. token 用量只采用供应商响应的数字。缺失用量是未知，不按零计算；报告展示有用量的调用数与总调用数。
5. 两次运行的耗时可对共同题报告差值；token 差值仅在双方所有成功调用都返回用量时给出。旧记录缺少遥测时保持未知。
6. 不计算货币费用，因为不同模型和服务商价格会变化，且缓存、输入输出 token 计价可能不同。

## 验收

- 客户端成功、失败和无 usage 的遥测测试；无敏感内容进入记录。
- 每次试验和运行汇总有耗时、调用数与用量覆盖率；离线模式调用数为零。
- 对比界面能显示可用的耗时与 token 差值，缺失数据有清楚提示。
- 后端全量测试及前端构建通过。
