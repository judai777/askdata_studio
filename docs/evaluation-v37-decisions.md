# 评测第三十七阶段决策：无模型候选 SQL 验证

日期：2026-11-01。承接[已审核任务集](evaluation-v28-review-round2.md)与[真实 SQL 指标](evaluation-v35-decisions.md)。用于在没有本地模型或远程 API Key 时验证外部生成的 SQL。

## 范围与口径

- 管理员可选择一条当前已审核通过的普通数据库查询题、一个固定 fixture，粘贴一条候选 SQL 并主动点击验证。每次只验证一题，SQL 最多 10,000 字符；不调用 Chat、Embedding 或 Rerank。
- 使用现有 DuckDB 只读校验与管理员表权限，在所选 fixture 上执行候选和标准答案。外部数据读取表函数显式拒绝。返回执行成功、结果是否等价、现有判分检查，以及候选与标准结果的前 10 行预览。结果预览用于排查，不作为完整结果导出。
- 澄清、问候和权限探针题不适用单条 SQL 验证；这些题依赖交互或权限过程。标准答案不在此入口显示 SQL 正文。
- 此入口不创建真实模型运行记录，也不产生 Schema 字段召回、远程用量或模型准确率。错误 SQL 不能绕过现有只读执行器。

## 验收

正确 SQL 通过；安全但错误的 SQL 返回结果不匹配；写入 SQL 被拒绝；未审核或过程题被拒绝；非管理员不可访问。前端构建及后端测试通过。
