# 评测第三十八阶段决策：批量候选 SQL 验证

日期：2026-11-01。承接[单题无模型验证](evaluation-v37-decisions.md)。本阶段让管理员一次提交多题候选 SQL，生成可下载的无模型汇总。

## 输入与执行

- 输入 JSON：`{"fixture_id":"edge_v3","candidates":[{"task_id":"mock.region_sales","sql":"SELECT ..."}]}`。每次 1–20 题，题目 ID 不可重复，SQL 每条最多 10,000 字符。固定数据集只选择一次。
- 所有题必须是当前人工审核通过的普通 SQL 题。提交前整体校验；题目不合法时整批拒绝，避免部分提交造成误解。SQL 本身执行失败则保留该题失败结果，不中止其余题。
- 一批只创建一次临时 fixture，顺序执行候选和标准 SQL；复用现有只读与外部表函数校验。返回任务版本、数据指纹、提交指纹、每题执行与结果判定及总数。
- 页面支持粘贴 JSON 或选取本地 JSON 文件。下载报告只含任务 ID、判分布尔值、数量与指纹；不含候选 SQL、标准 SQL、结果行或错误正文。页面可显示简短执行错误用于排查。
- 不调用模型，不写入真实模型运行历史，也不产生 Schema 检索、远程用量或模型准确率。

## 验收

正确与错误 SQL 混合批次按题计数；无效题、重复题和超额批次被拒绝；写入语句记为执行失败；管理员接口与 JSON 下载可用。后端测试、前端构建及 CI 通过。
