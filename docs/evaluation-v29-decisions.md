# 评测第二十九阶段决策：真实评测起步配置

日期：2026-11-01。前置条件：任务集 v5.2 的 14 题已完成人工复审，结论见[第二轮复审](evaluation-v28-review-round2.md)。本阶段帮助管理员用已审核题启动小规模真实评测，以取得后续失败分析与人工标注的素材。

## 选择

- 管理员页面增加“准备三题真实评测”操作，只填入配置，不自动发送远程请求。
- 固定选择 `mock.target_comparison`、`grain.unique_customers`、`time.july_august`，覆盖目标关联、去重粒度、历史与当前跨表时间口径。仅当三题当前审核状态均为通过时可用；数据或题目变化造成审核过期时应先复审。
- 预设实时模式、`edge_v3`、每题 1 次试验、远程 HTTP 请求上限 20。Chat 模型沿用当前已选登记模型。启动时继续显示现有确认弹窗；请求上限不等于费用上限。
- 不把预设运行结果当作总体准确率。先查看逐题轨迹、失败阶段和模型用量，再对有效实时试验做人工标签。后续是否扩展题集依据这些证据决定。

## 验收

点击预设后只改变页面选题与运行选项，不创建运行、不调用远程 API；未审核通过时显示原因。管理员仍可改题、改模型和数据，并须主动点击“开始评测”。前端类型检查和构建通过。
