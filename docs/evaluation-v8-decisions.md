2. 结果相同只说明当前 fixture 对该错误 SQL 不敏感；不等于证明模型答案正确或 SQL 语义等价。
3. “澄清后选错历史表”只审计最终 SQL 结果。是否先询问用户、是否按用户选择恢复，仍由原有澄清任务的流程判分检查。
4. 审计报告给漏检样例提供补数建议，页面优先显示这些待改进项。错误清单提升到 v1.1；任务集与 oracle 版本不变。
