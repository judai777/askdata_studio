# 评测第三十九阶段决策：目标域开发题试点

日期：2026-11-01。承接[430 题基准定义](evaluation-v24-decisions.md)和[准备度清单](evaluation-v31-decisions.md)。

## 本阶段范围

- 先加入 3 道 `ecommerce_ops` 开发题草稿：订单状态计数、2026 年 8 月完成订单的地区实付金额、按店铺类型关联统计同口径金额。覆盖简单题 2 道、中等题 1 道，题族各异；不把它们当成已审核或已测模型结果。
- 目标域题只使用 `base` 数据集。现有 `edge_v1` 至 `edge_v3` 仅变异 `askdata_mock`，不能让目标域题借用它们的边界覆盖结论。
- 目标域运行、候选 SQL 验证与人工审核指纹必须包含 `ecommerce_ops` CSV 内容。旧 `askdata_mock` 指纹算法及已审核记录维持原义。混合数据库批次暂不接受，避免一个指纹掩盖两套不同数据。
- 将题目说明与标准 SQL 交由现有管理员审核页展示；只有人工确认后才可进入候选 SQL 批量验证。目标字段标签仍待逐题确认，不自动写为 approved。

## 验收

3 道草稿在目标域 base 上能执行并产生非空、可区分的结果；目标域 CSV 变化会改变指纹；目标域边界数据集及跨库批次被拒绝；原有审核与离线门槛继续有效。后续先完成这 3 题的人工复核和错误 SQL 区分力审计，再扩展至 49 题。

## 审核前的离线证据

- `commerce.order_status_count`：六种状态合计 12,000 单；其中 `completed` 8,109、`refunded` 721。错误 SQL 若漏退款状态，结果从六行变五行。
- `commerce.august_completed_sales`：五个地区的 8 月完成订单实付额合计 855,823.40；漏月份过滤会得到跨 2025–2026 年的更大金额。
- `commerce.store_type_sales`：专营店 229,401.58、品牌旗舰店 523,596.09、自营 102,825.73；按地区代替 `store_id` 关联会多倍计入金额。

三种错误 SQL 均在当前 base 数据上得到不同结果，已加入确定性测试。人工仍需确认题目表述、完成状态和金额口径；此处不自动批准题目，也不为新题发布字段召回成绩。
