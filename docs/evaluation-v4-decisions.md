# 评测第四阶段决策记录

状态：已决策，2026-10-30。承接 [第三阶段决策](evaluation-v3-decisions.md)。

## 目标

现有运行报告能查看单次结果，无法判断调整模型、Prompt 或检索配置后哪些任务变好或退化。本阶段增加只读的两次运行对比，不触发模型调用。

## 对比规则

1. 只接受两次不同且已完成的运行。任务集版本、数据指纹、运行模式、试验次数必须一致；不满足时返回明确原因。
2. 仅对共同题目逐题比较，不用各自的总通过数直接相减。只在基线或候选中出现的题单独列出，避免隐藏覆盖率差异。
3. 逐题状态分为 `regressed`、`improved`、`still_passed`、`still_failed`。判分项在两次运行中取并集，列出由真变假、由假变真和缺失项。缺失不按通过处理。
4. 三次试验比较使用每题聚合后的 `passed`，因此表示 Pass³ 是否变化；试验次数不一致时禁止比较。权限探针另标明为护栏任务。
5. UI 在历史运行中选择基线和候选，显示共同题数量、覆盖差异、退化题及判分项变化。对比 API 只读且限管理员访问。

## 验收与边界

- 纯函数比较器有退化、改善、覆盖差异及拒绝不可比运行的测试。
- 管理员 API 和 Vue 页面可对历史运行出报告；旧版本记录若元数据相同仍可相互比较。
- 本阶段不声称差异具有统计显著性，也不自动判断改动原因。真实模型间对比需要用户运行两份可比的实时任务集。
