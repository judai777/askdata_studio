# 评测第十阶段决策记录

状态：已决策，2026-10-30。承接[第九阶段决策](evaluation-v9-decisions.md)。

## 目标与语义

管理员可请求取消后台评测，以停止后续题目和独立试验，减少不必要的远程模型调用。单次已开始的模型/工具调用继续等待返回；本阶段不尝试强杀线程或中断 HTTP 请求。

## 状态与数据

1. `POST /api/eval/runs/{id}/cancel` 仅管理员可用，只接受当前进程内活跃的后台运行。请求后显示 `cancel_requested`，后台在当前试验结束或下一试验开始前进入终态 `cancelled`。
2. 已完成的试验与逐次指标保留。若某题只完成部分试验，该题标记 `incomplete`，可查看轨迹和耗时，但不计入通过、完成、安全、过程或 Pass³。报告分母仍为启动时选择的任务数，并展示已完成试验数。
3. `cancelled` 运行不能重放，也不能参与两次运行的回归对比。取消完成后释放单进程运行槽；已完成、失败、取消或非当前进程的运行不可再取消。
4. `cancel_requested` 是当前进程的暂态展示；服务重启时，尚未写入终态的 `queued`/`running` 记录按 `interrupted` 处理。同步脚本接口不引入取消；本功能只针对后台启动的评测。
5. UI 在排队、运行、取消等待期间持续轮询，并显示“停止后续试验”与取消状态。请求后按钮禁用，直到终态。

## 验收

- 取消正在执行的三次试验时，当前试验返回后不再启动后两次；其轨迹保留且不计通过。
- 取消后可启动新运行；终态取消不能重放或比较；普通用户不能请求取消。
- 后端测试、前端类型检查与生产构建通过。
