# 评测第十四阶段决策记录

状态：已实现，2026-10-30。承接[评测路线图](evaluation-roadmap.md)。

## 目标

在管理员评测台导出单次运行的可分享 JSON 摘要，便于代码评审和面试演示。导出仅读取已有记录，不运行模型、不重新判分。

## 数据边界

1. 仅导出已结束的运行；取消的运行可以导出，保留 `cancelled` 与逐题 `incomplete` 标记。运行中的结果随时变化，不生成报告。
2. 文件包含导出格式版本、运行 ID、模式、时间、任务/数据/oracle 指纹、实现来源指纹、安全配置快照、人工审核覆盖度、总分、逐题和逐次判分、调用与阶段指标。只保留固定字段，不直接复制完整运行对象。
3. 不导出原始问题、SQL、结果行、模型输入输出、工具参数、异常文本、审核意见、密钥和接口地址。阶段只导出阶段名、调用数、失败数与耗时；旧记录缺失指标时保持 `null`。
4. 后端管理员接口返回 JSON；前端下载同一份 JSON，文件名带运行 ID。格式用 `format_version` 标识，后续扩展可兼容旧文件。
5. 报告定位为评测摘要，不能代替管理员页面中的原始轨迹，也不能把离线演示分数称为模型准确率。

## 验收

- 管理员可以下载已完成或已取消的报告；普通用户无权导出，运行中返回冲突。
- 导出包含复现实验所需的版本和判分摘要，敏感正文及数据行不进入文件。
- 后端测试、前端类型检查和生产构建通过。
