# 评测第三十阶段决策：真实运行的审核覆盖提示

日期：2026-11-01。任务集 v5.2 已通过人工复审。服务端现有运行快照保存 `review` 计数；本阶段让启动前和历史报告都能看到该证据。

## 选择

- 管理员准备实时评测时，页面显示当前选题中已通过与未通过审核的数量。
- 点击开始后先重新读取审核状态，再展示远程调用确认；若有未通过审核的题，确认文字明确提示其结果仅用于探索，不能代表已审核题集成绩。离线演示仍可使用任何题。
- 运行报告显示创建时保存的审核覆盖度，旧运行缺少快照时显示未知。历史快照不根据当前审核状态重写。
- 不新增服务端硬性阻止，以保留对待审核题的探索能力；已有请求次数上限与用户确认继续生效。

## 验收

页面切换选题后计数随之变化；实时启动前使用最新审核数据；运行报告读取保存的 `review`，不以当前状态替代。前端类型检查和构建通过。
