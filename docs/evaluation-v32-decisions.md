# 评测第三十二阶段决策：字段级 Schema 指标协议

日期：2026-11-01。承接[430 题基准决策](evaluation-v24-decisions.md)和[准备度清单](evaluation-v31-decisions.md)。本阶段先实现可复用的纯判分函数，不给现有 14 题生成未经审核的目标字段标签。

## 字段身份与分母

- 字段以 `database_id.table_id.field_name` 完整键标识；同名字段分属不同表时不合并。
- 最终召回字段取检索结果的 `hits`，同一字段重复出现只计一次。用户确认后加入的字段若出现在最终 `hits` 中，也计入召回集合；调用来源另由轨迹解释。
- 每题目标字段集合必须非空，且由标准 SQL 与人工审核确定。目标标签缺失时不出分数；不能从 `required_metric_fields` 或 `required_time_fields` 直接推断完整目标集合。
- 召回率为交集数 / 目标字段数；准确率为交集数 / 最终召回字段数。最终召回为空且目标非空时，两者均记 0。重复字段不改变分母。
- 汇总时只纳入标签有效的题，报告题数和宏平均；路由、澄清、权限题若无完整字段标签，不进入字段指标分母。

## 验收

纯函数对正确字段、同名异表、重复字段、空召回和缺失标签均有测试。未产生真实模型成绩，后续在目标字段人工审核后再接入运行报告。
