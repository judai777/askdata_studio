# 评测第十三阶段决策记录

状态：已实现，2026-10-30。承接[评测路线图](evaluation-roadmap.md)。

## 目标

为实时评测增加阶段耗时与失败归因，帮助定位问题出在请求预处理、Schema 检索、单库 Agent、MCP 工具或结果整理。普通问数 API 默认不收集这类评测遥测。

## 数据规则

1. 在 LangGraph 主要节点外计时，记录固定阶段名、毫秒耗时、成功状态和有限的失败类型。人工等待澄清的暂停节点不计时。
2. 单库 Agent 的每次 MCP 工具调用单独计时。工具耗时包含在 Agent 阶段耗时内，属于嵌套指标；不能与父阶段相加得出总耗时。
3. 现有 Chat、Embedding、Rerank 调用摘要附上当时阶段名。继续不记录密钥、接口 URL、原始 Prompt、请求正文或模型响应正文。
4. 每次试验保存阶段轨迹；逐题与整次运行按阶段聚合调用次数、失败次数和累计耗时。无阶段遥测的离线演示、旧记录显示“未知/不适用”，不伪造零耗时。
5. 回归对比展示共同题的阶段耗时变化，只在两份运行都具备该阶段数据时给出差值。阶段指标用于定位原因，仍由任务判分决定通过与否。

## 验收

- 正常与失败路径均能记录阶段耗时及有限的失败类型；工具子阶段单独可见。
- 模型调用摘要带阶段名，不包含敏感请求内容。
- 页面展示逐题阶段归因和回归阶段差异，离线演示不显示假数据。
- 后端测试、前端类型检查与生产构建通过。
