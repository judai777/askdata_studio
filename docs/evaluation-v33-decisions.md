## 标注规则

- 从每题标准 SQL 的输出、聚合、过滤和关联条件提取字段；JOIN 两侧同名字段分别计入。使用 `database.table.field` 完整键。
- 澄清题以选择“当前订单”后的最终查询为标注对象。跨表月份题分别计入历史表和当前表字段。
- 保存为 `draft`，只做表字段存在性和题目覆盖检查。SQL AST 自动提取不能替代业务审核，草稿不进入运行报告或模型指标。
- 审核时重点确认过滤字段是否应计入目标、JOIN 键是否两侧都必需、同名异表是否分开，以及用户手动补入字段的召回口径。审核通过后另起版本并接入真实运行。

## 验收
