# 评测第二十一阶段决策记录：人工轨迹标签与判分校准

状态：已决策，2026-10-31。承接[评测路线图](evaluation-roadmap.md)的 P1 阶段与[第十九阶段决策](evaluation-v19-decisions.md)。

## 目标

为每次运行中的具体试验建立人工复核入口，记录完成度、安全、过程与回答质量的判断，并统计人工标签与确定性判分的分歧。缺少人工标签时保持“尚无校准证据”，不生成虚假的准确率。

## 决策

1. 管理员可对已结束运行中真实存在的试验提交四个维度的 `pass`、`fail` 或 `unsure` 标签，并填写依据。系统保留标签历史、审核人和时间；标签文件不进入 Git。`unsure` 不参与一致率分母。回答质量没有自动对应维度，只显示人工分布，不算自动判分一致率。
2. 标签绑定运行 ID、任务 ID、试验序号、任务/数据/答案版本与该试验结果的 SHA-256 短指纹。轨迹或评测依据变化时旧标签标为过期，不能计入统计。存储只保留标签、指纹、意见和审核元数据，不复制问题、SQL、模型正文或数据行。
3. 离线演示允许练习标注，但不计入真实模型校准。统计只汇总 `live` 运行的有效标签，并按原始 `grader_hash` 分组。对完成度、安全、过程分别给出 TP/FP/FN/TN、未确定数和有效样本数；样本为零时一致率为 `null`。统计是分歧定位工具，不以小样本推断模型准确率。
4. 只允许管理员读取、提交标签和查看汇总。每次提交必须带页面所见轨迹指纹，服务端验证后原子写入，避免提交到已变化的试验。相同试验再次提交形成新历史记录，当前统计只用最新有效标签。
5. UI 在运行详情逐次展示自动判分和人工标签表单；独立汇总区展示真实运行的校准覆盖度与分歧计数。人工任务审核与轨迹标签是两种不同工作，不互相代替。

## 验收

- 真实试验可标注、覆盖和查看历史；未知任务/试验、空依据、非法标签和过期指纹被拒绝。
- 离线演示标签不进入真实模型统计；缺失/不确定标签不制造准确率；已知正反分歧计数正确。
- 普通用户无法读取或提交标签；标签文件不包含原始轨迹。
- 后端测试、前端类型检查与构建、离线门槛及 GitHub Actions 通过。
