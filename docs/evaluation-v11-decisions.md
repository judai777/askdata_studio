# 评测第十一阶段决策记录

状态：已决策，2026-10-30。承接[第十阶段决策](evaluation-v10-decisions.md)。

## 问题与选择

现有运行记录保存模型名、任务集、数据和标准答案指纹，但提示词或工作流代码改动后，两次运行仍会被直接比较，报告无法说明实现是否变化。本阶段为实时运行保存可追溯的实现指纹和非敏感模型配置快照，并在回归对比中展示差异。

## 指纹范围

1. 提示词指纹覆盖请求预处理、单数据库 Agent、数据问答、结果整理、MCP 指令相关源码，以及两个应用 Skill 的 `SKILL.md` 和 `config.json`。它是“提示词相关源码指纹”，代码重构也可能改变值，不能解释具体提示词差异。
2. 工作流指纹覆盖服务入口、LangGraph 工作流、检索、数据库执行、模型客户端和 Schema 定义相关源码。文件名和文件字节按稳定顺序哈希；不包含 `.env`、密钥、运行日志或用户数据。
3. 配置快照仅保存模型名称、温度、超时/重试、检索参数、字段/工具限制与上下文/短期记忆设置。不保存 API Key、接口 URL 或请求正文。离线演示记录为 `demo`，不宣称使用了实时 Agent 指纹。

## 回归对比规则

任务版本、fixture、oracle、模式和试验次数仍是硬性可比条件。模型、提示词指纹、工作流指纹或配置不同是允许比较的实验变量；报告显示“实现已变化”及逐项差异。两份新记录完全相同时显示“实现一致”。任一旧记录缺少快照时显示“版本信息不足”，不推断相同或不同。

指纹只说明本地可见文件是否变化，不能证明远程服务权重、供应商版本或外部依赖完全相同。实时模型结果仍需通过逐题判分和重复试验观察。

## 验收

- 新实时运行记录含非敏感来源快照；离线运行明确标记为 `demo`。
- 修改提示词相关文件会改变提示词指纹，工作流文件变化会改变工作流指纹。
- 回归对比能报告实现一致、变化或信息不足，且不阻止有意进行的模型/Prompt A/B 对比。
- 后端测试、前端类型检查与生产构建通过。
