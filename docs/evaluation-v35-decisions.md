# 评测第三十五阶段决策：真实 SQL 执行与结果指标

日期：2026-11-01。依据[430 题基准定义](evaluation-v24-decisions.md)。现有逐题判分已有结果行集比较；本阶段另设用于统计的 SQL 执行与结果指标，不改变任务通过规则。

## 口径

- 仅统计真实运行中预期 `database_query` 的非权限探针题。一次独立试验计一个样本；Pass³ 的三次试验分别计入，报告明确分母是“试验次数”。问候与权限拒绝题不进入分母。
- 澄清题使用用户选项恢复后的最终结果；初次等待澄清不单独计入 SQL 分母。
- SQL 执行成功须有目标数据库的 `query_数据库名` 工具调用、该调用 `success=true`，且调用记录包含非空 SQL。只有最终状态 `completed` 或生成了 SQL 字符串均不足以证明执行成功。异常、未调用工具、被拒绝和执行错误计为失败。
- 结果正确须先有 SQL 执行成功，再满足现有标准行集 `result` 检查。每次运行展示执行成功数/样本数与结果正确数/样本数；两者均不因缺少轨迹而缩小分母。
- 离线演示和旧运行不补造这两个指标。摘要导出仅保留布尔值与汇总计数，不包含 SQL 或结果行。

## 验收

测试覆盖成功、失败、无工具调用、错误数据库、澄清恢复、非 SQL 题和离线演示；报告与导出保持相同分母。真实模型数字仍需管理员主动运行后才产生。
