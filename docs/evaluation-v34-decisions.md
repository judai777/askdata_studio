# 评测第三十四阶段决策：字段标签审核与真实运行接入

日期：2026-11-01。项目使用者逐题认可[第三十三阶段](evaluation-v33-decisions.md)的 12 组字段草稿，包括过滤字段、JOIN 两侧键、澄清后最终查询及跨表月份字段。问候与权限拒绝题不参与字段指标。

## 决策

- 将已确认标签单独保存为 `field_targets.json`，版本 1.0，并保留原草稿作为审核历史。标签关联任务集 v5.2；版本不匹配时不得产生字段成绩。
- 只对真实运行且返回最终 `retrieval.hits` 的试验计算字段指标。澄清题使用恢复后的结果；缺少检索证据的试验记为“不可计算”，不按零召回处理。明确返回空 hits 才记零。
- 每次运行冻结标签内容与指纹，逐试验保存字段数量、召回率和准确率，汇总只对可计算试验取宏平均并报告分母。离线演示与旧运行不补造指标。
- 字段指标独立于既有任务通过判定；不改变旧判分器结果。摘要导出只包含聚合数值与计数，不输出字段名单。

## 验收

正反例覆盖：正常命中、空命中、缺检索证据、澄清恢复、离线演示、标签版本不匹配。完整后端测试、前端构建和离线门槛通过。
