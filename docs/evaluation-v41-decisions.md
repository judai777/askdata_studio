# 评测第四十一阶段决策：页面作业控制与真实模型回归门槛

日期：2026-11-10。承接[第四十阶段作业编排](evaluation-v40-decisions.md)与[评测平台调研](evaluation-platform-research.md)。当前管理员页只能查看 CLI 作业；本机已审核 17 题，但未配置远程 API 密钥，因此本阶段不能报告新的真实模型成绩。

## 决策

1. 管理员可从现有已审核题目中选择同一数据库的题，指定模式、fixture、试验次数、白名单 Chat 模型和整个作业的远程 HTTP 请求预算。页面在真正启动 live 作业前展示请求上限与可能产生费用的确认框。后端再次校验所有参数；无密钥时返回明确错误，不创建假成绩。
2. 后端以单进程、单作业后台执行器调用现有 `run_campaign`。作业清单先持久化为 `queued`，页面轮询只读状态；完成片不重复执行。失败或中断片续跑时再次传入完整原参数，live 重试须再次确认可能重复请求。保留 CLI 的文件锁，拒绝同 ID 并发及计划指纹漂移。进程重启后的后台作业显示中断，可从页面显式续跑。
3. 基线必须由管理员从**已完成的真实模型作业**中明确批准，填写审核意见。保存该作业 ID、计划指纹、来源和逐题通过情况，不复制 SQL、结果行或模型正文。候选回归门槛要求完整任务集合、相同 fixture、试验次数、题目/答案/判分/字段标签与 Prompt/工作流/非 Chat 配置；只允许 Chat 模型变化。缺题、失败片、未知版本或基线原来通过的题退化均不能通过门槛。基线分数本身仍需人工解释，不能把低质量基线当质量证明。
4. CI 保持确定性检查和无模型作业冒烟；真实模型门槛只对显式运行且已批准的本地基线比较，不在每次 push 时发送远程请求。没有真实运行时可验证 API、安全和门槛逻辑，但不能公布新准确率。
5. 真实作业汇总仅聚合已完成片的试验指标，包括字段级 Schema 宏平均召回、SQL 执行与结果正确次数、模型调用摘要；未完成片和无模型作业不生成真实模型指标。

## 验收

- 页面可启动 demo 作业并观察分片进度；live 在无密钥时明确拒绝，在有密钥时必须经过预算确认。
- 页面续跑不重复已完成片；live 未完成片重试需要再次明确确认。
- 非管理员无法发起、续跑、批准基线或读取回归结果；基线批准与门槛判定可追溯。
- 完整后端测试、离线门槛、前端构建和 GitHub Actions 通过；真实模型指标仅在确有新运行时报告。
