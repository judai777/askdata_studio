# 评测第三十六阶段决策：耗时均值与 P95

日期：2026-11-01。依据[430 题基准定义](evaluation-v24-decisions.md)及现有阶段轨迹。`mcp_tool_call` 是数据库工具请求耗时，包含工具传输与执行；不把它称为纯 DuckDB SQL 执行耗时。

## 口径

- 仅统计真实运行中的 SQL 题试验，与第三十五阶段的 SQL 指标采用同一试验集合。包含失败试验；未完成的试验没有记录，不进入分母。
- 端到端耗时取每次试验的 `metrics.elapsed_ms`，从试验开始到取得结果或异常，包含模型、检索、工具与整理。
- 数据库工具耗时取阶段轨迹中 `stage=mcp_tool_call` 且工具名以 `query_` 开头的有效非负时长；一次试验可有多次调用，按调用数统计。失败调用若有时长也进入分布。
- 分别报告有效样本数、均值和最近秩 P95（排序后第 `ceil(0.95*n)` 个值）；没有有效时长时结果为未知，不填 0。两个阶段可能重叠，不相加。
- 离线演示和旧运行不补造耗时分布。导出仅包含数字，不包含工具参数或 SQL。

## 验收

测试覆盖多次调用、失败试验、缺失/非法时长、最近秩边界与离线演示；前后端构建和 CI 通过。
